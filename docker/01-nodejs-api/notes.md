# Docker Notes

## Docker Image

A Docker image is a read-only template used to create containers.

## Docker Container

A running instance of a Docker image.

## Dockerfile

A text file that contains instructions for building a Docker image.

## Docker Build

Creates a Docker image.

## Docker Run

Starts a container from a Docker image.

## Docker Layers

Each Dockerfile instruction creates a separate cached layer.

## Port Mapping

Maps a port on the host machine to a port inside the container.
