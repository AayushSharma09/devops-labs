# Git Workflow Lab

## Objective

Learn the Git workflow used in professional software teams.

---

## Topics Covered

- Git Repository
- Git Clone
- Git Status
- Git Add
- Git Commit
- Git Push
- Branches
- Feature Branch Workflow

---

## Commands Used

```bash
git clone
git status
git add .
git commit
git push
git checkout -b
git branch
```

---

## Learning Outcome

Understand how developers collaborate using Git feature branches instead of directly working on the main branch.
